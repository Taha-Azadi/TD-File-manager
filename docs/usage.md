# TD File Manager - Usage Guide

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python main.py
   ```

## Features

### Navigation
- **Back/Forward**: Navigate through folder history
- **Up**: Go to parent directory
- **Address Bar**: Click to edit path, breadcrumb navigation
- **Tree Pane**: Left sidebar for quick folder browsing

### View Modes
- **Details**: Table view with columns (Name, Date Modified, Type, Size)
- **Icons**: Large icon grid view
- **List**: Compact list view
- **Tiles**: Medium icon list view

### File Operations
- **New Folder**: Ctrl+Shift+N
- **Cut**: Ctrl+X
- **Copy**: Ctrl+C
- **Paste**: Ctrl+V
- **Delete**: Delete key
- **Rename**: F2
- **Refresh**: F5

### Search
Type in the search box and press Enter to search within the current folder.

### Themes
Toggle between Light and Dark mode using the theme button.

### Drag & Drop
Drop files from external applications into the file manager.
